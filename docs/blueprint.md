# **App Name**: Wellbeing Navigator

## Core Features:

- Data Integration: Data Ingestion & Processing Tool: Gathers user data from various sources (assessments, demographics, activity logs) to build a comprehensive user profile. Uses AI tool for cleaning and standardizing data, respecting user privacy.
- Personalized Profiles: User Profiling Engine: Leverages machine learning algorithms (clustering, embeddings) to create dynamic user personas. Uses AI to identify patterns in user behavior and wellbeing needs.
- Resource Recommendations: Personalized Recommendation System:  Suggests relevant in-app resources (sessions, videos) and external sources (e.g., NHS articles) based on user profile, preferences and goals. The LLM serves as a reasoning tool to incorporate these considerations.
- AI-Driven Support: LLM-Powered Dialogue Agent: Offers personalized guidance and answers user queries using a fine-tuned LLM. Allows for natural language interaction and provides empathetic support.
- Visualized Insights: Provides users with a visual overview of their wellbeing data, progress towards goals, and personalized recommendations. Includes interactive charts and graphs.
- Continuous Improvement: Continuously tests and refines the AI agent's recommendations and dialogue strategies through A/B testing and user feedback analysis.

## Style Guidelines:

- Primary color: Calming blue (#5DADE2) to promote trust and tranquility in the app experience.
- Background color: Light gray (#F2F4F4) for a clean and neutral backdrop, ensuring readability and focus on the content.
- Accent color: Soft teal (#45B39D) to highlight key actions and information, such as call-to-action buttons, progress indicators, and important recommendations.
- Body font: 'PT Sans', a humanist sans-serif for readability and a modern, warm feel.
- Headline font: 'Space Grotesk', a geometric sans-serif for headlines. If the headline text gets too long, use 'Inter' as the body text.
- Use a set of custom icons with a minimalist, geometric style that are consistent and intuitive.
- Incorporate subtle animations such as smooth transitions, loading spinners, and interactive feedback to enhance user experience.
